# TikTok FYP Content Predictor

Aplikasi difokuskan pada prediksi potensi konten masuk FYP/rekomendasi.

Target model menggunakan proxy analitik: video pada top 20% jumlah plays dalam dataset dianggap sebagai "high discovery potential". Ini bukan data internal algoritma TikTok.

Jalankan:
pip install -r requirements.txt
streamlit run app.py
